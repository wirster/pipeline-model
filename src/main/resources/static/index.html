说明：
- 为每个"属性值"选择并上传对应的模型包（ZIP格式）。
- ZIP包中应包含：.obj模型文件、.mtl材质文件、相关贴图图片文件。
- 上传成功后即建立"属性值 → 模型包"映射。
- 提交建模任务时，会随参数一并提交映射，服务端按附属物类型优先使用对应模型。

说明：
- 直接按特征类型上传对应模型（无需手动添加变体名称）。
- ZIP包中应包含：.obj模型文件、.mtl材质文件、相关贴图图片文件。
- 特征模型由特征 + 特征类型唯一确定。
